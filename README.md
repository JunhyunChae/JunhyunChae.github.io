# junhyun-chae.github.io

My personal site: https://junhyun-chae.github.io

Built with Jekyll on GitHub Pages. English at `/`, Japanese at `/ja/`.

## Writing a post

Add a Markdown file to `_posts/` named `YYYY-MM-DD-title.md`:

```markdown
---
title: Title of the post
lang: en   # or ja
---

Text goes here.
```

Push to `main` and it shows up under `/writing/`.

## Preview

```
jekyll serve
```
